# Créditos e licenças

Os 17 sprites PNG e os 8 arquivos de áudio WAV em `core/assets/` foram gerados proceduralmente por `tools/GeradorDeAssets.java` para este projeto. Não foram utilizados recursos gráficos ou sonoros de terceiros. O gerador emprega apenas bibliotecas Java padrão (`java.awt`, `ImageIO` e `javax.sound.sampled`).

Caso sejam substituídos por imagens ou sons externos, registrar aqui autor, URL de origem, licença e arquivos correspondentes.
